# Platform content review

Reviewed on 3 November 2026. Scope: the 16 apps already listed in the directory, in English and Romanian. Changes are in `src/data/entries.ts` and `src/data/entries-ro.ts`.

The review compares published platform guidance with the guide text. It does not test settings in child accounts. The existing source panels explain that distinction. Device, operating-system and network guides are outside this pass.

## Source coverage

Fourteen guides carry a 3 November source-check date. WhatsApp and Telegram retain the September full-review date, with explicit November notes for the narrower announcement/eligibility checks. Their older setup paths were not all reverified.

Some official help portals restrict automated retrieval. Twitch’s help page returned a loading error, and Steam’s returned an image shell; the relevant details were checked in indexed official text. Their availability notes disclose this. WhatsApp help pages also returned no readable body, so the wider review date was preserved. A failed Telegram channels-page retrieval was not used as evidence of a new change.

## Language pass

Applied the humanizer skill to the changed guides in both languages. Replaced stock callout labels, inflated claims and repetitive warnings with direct instructions. Rewrote older Romanian passages with diacritics and clearer phrasing. Kept product setting names where parents need to recognise them in an app.

Stable slugs, categories, risk levels, risk-bar positions, badges and related links remain unchanged. No deployment or Git publication is included in this update.
